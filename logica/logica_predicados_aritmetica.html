A linguagem da aritmética

Uma linguagem de primeira ordem feita sob medida para os números naturais: seus parâmetros, os axiomas de Peano e um sistema de regras de inferência — com derivações comentadas, passo a passo, algumas certas e algumas erradas de propósito.

Assinatura

Os parâmetros da aritmética

Dos símbolos lógicos da página anterior, usam-se todos, inclusive a igualdade. Dos parâmetros, só estes quatro — e nenhum símbolo predicativo: a única relação é a igualdade.

∀quantificador

percorre os números naturais

0constante

sfunção unária

+ ·funções binárias

Não há algarismos

A linguagem não tem os símbolos 1, 2, 3. Cada número se nomeia pela composição: 1 é s(0), 2 é s(s(0)), e o numeral de n é s aplicado n vezes a 0.

O dois não tem nome próprio; tem uma descrição — o sucessor do sucessor do zero. Nesta linguagem, só o zero é um símbolo, no sentido da página anterior; todos os outros números são nomeados por termos compostos.

O modelo que se tem em mente

A estrutura padrão chama-se ℕ: o universo são os números naturais, 0 é o zero, s é somar um, + e · são a soma e o produto de sempre.

Convenção de escrita: + e · vão entre os argumentos, e não na forma +(x, y); o produto tem precedência sobre a soma, de modo que x · y + x abrevia (x · y) + x.

Axiomas

Os axiomas de Peano

Seis axiomas e um esquema. Os dois primeiros falam do sucessor; os quatro seguintes definem a soma e o produto; o esquema de indução amarra tudo.

axiomalê-se
A1∀x ¬(s(x) = 0)zero não é sucessor de nenhum número
A2∀x ∀y (s(x) = s(y) → x = y)números com o mesmo sucessor são iguais
A3∀x (x + 0 = x)somar zero não muda nada
A4∀x ∀y (x + s(y) = s(x + y))somar o sucessor de y é tomar o sucessor da soma com y
A5∀x (x · 0 = 0)multiplicar por zero dá zero
A6∀x ∀y (x · s(y) = x · y + x)multiplicar pelo sucessor de y é multiplicar por y e somar mais um x
Ind(φ(0) ∧ ∀x (φ(x) → φ(s(x)))) → ∀x φ(x)se vale para 0, e passa de cada número ao seguinte, vale para todos

A3 a A6 são um programa

Lidos da esquerda para a direita, os quatro axiomas da soma e do produto são uma definição recursiva — o mesmo desenho de uma função que desce até o caso base:

soma(x, 0)    = x                    -- A3
soma(x, s(y)) = s(soma(x, y))        -- A4
prod(x, 0)    = 0                    -- A5
prod(x, s(y)) = soma(prod(x, y), x)  -- A6

A recursão é sempre no segundo argumento. Essa assimetria vai pesar: x + 0 = x é axioma, e 0 + x = x não é.

A indução é um esquema

Em segunda ordem, a indução seria um único axioma, quantificando sobre todas as propriedades de números. Em primeira ordem só se quantifica sobre números — não sobre propriedades.

A saída é um esquema: uma instância para cada fórmula φ(x) da linguagem, infinitas ao todo. É o mesmo recurso dos esquemas de Łukasiewicz, na página de lógica proposicional.

Na notação, φ(0) é φ[0/x], e φ(s(x)) é φ[s(x)/x] — a substituição da página anterior.

Cálculo

Calcular é derivar

Um termo tem um valor. Há duas maneiras de chegar a ele: perguntando ao modelo, ou reescrevendo o termo com os axiomas. Os dois painéis abaixo fazem uma coisa cada.

    Semântica e sintaxe, lado a lado. O painel da esquerda calcula o valor do termo no modelo: é semântica, e precisa de uma atribuição para as variáveis — índices, como na página anterior; o zero não precisa de nada. O da direita não sabe o que os símbolos significam: só troca partes do termo usando A3–A6 da esquerda para a direita, sempre pelo trecho mais interno. Quando o termo não tem variáveis, a reescrita termina num numeral, e cada passo é uma linha de demonstração: uma instância de axioma seguida de substituição de iguais.
    Experimente x + 0 e depois 0 + x. O primeiro se reescreve em um passo. O segundo não se reescreve nunca: o segundo argumento é x, que não é 0 nem s(…), e nenhum axioma se aplica. É aqui que a indução vai ser necessária — a última derivação correta, mais abaixo, trata exatamente disso.

    Regras

    Um sistema de regras de inferência

    A página de lógica proposicional usava um sistema de Hilbert: três axiomas e uma única regra. Aqui o peso passa para as regras. Os dois tipos de sistema não são rivais — no caso proposicional, Reckhow mostrou que eles se simulam mutuamente, com custo no máximo polinomial —, mas este fica bem mais perto do modo como se raciocina.

    Os esquemas proposicionais, convertidos

    São os esquemas de sempre. A conversão está no que pode ocupar os lugares de α, β e γ: agora, qualquer fórmula de primeira ordem. Na derivação “2 ≠ 1”, abaixo, o modus tollens opera sobre igualdades entre termos.

    MPmodus ponensα,  α → β  ⊢  β
    MTmodus tollensα → β,  ¬β  ⊢  ¬α
    Conjconjunçãoα,  β  ⊢  α ∧ β
    Simpsimplificaçãoα ∧ β  ⊢  α
    Adadiçãoα  ⊢  α ∨ β
    SHsilogismo hipotéticoα → β,  β → γ  ⊢  α → γ
    SDsilogismo disjuntivoα ∨ β,  ¬α  ⊢  β
    PCprova condicionalsupondo α, deriva-se β  ⊢  α → β

    A prova condicional abre uma caixa: supõe-se α, e tudo o que se derivar ali depende da suposição. Ao fechar a caixa, conclui-se α → β, e as linhas de dentro não podem mais ser citadas. Na página de lógica proposicional, essa passagem era o teorema da dedução — um metateorema, provado sobre o sistema. Aqui é uma regra, usada dentro dele.

    Os axiomas — A1 a A6 e qualquer instância do esquema de indução — podem ocupar qualquer linha, justificados só pelo nome.

    As condições são o conteúdo das regras. Sem elas, as quatro regras dos quantificadores são quase óbvias. Cada condição bloqueia um sofisma específico — as derivações falaciosas, adiante, mostram qual.
    Por que “instanciação”. IU e IE produzem uma instância a partir de uma fórmula geral, como se cria um objeto a partir de uma classe na orientação a objetos. A IE é a que mais lembra: cria um indivíduo novo, com identidade própria, que não se confunde com nenhum outro — e que só existe enquanto dura a derivação.

    Limites

    Por que, desta vez, não há ferramenta

    Não há tabela para percorrer

    Na lógica proposicional, uma ferramenta decidia a validade de qualquer fórmula percorrendo a tabela de verdade. Aqui não há tabela: o universo é infinito.

    E não é falta de engenho. Validade em primeira ordem é indecidível: não existe algoritmo que responda sempre, e corretamente, se uma fórmula qualquer é válida. É o resultado de Church e Turing, de 1936 — o mesmo que fecha o painel da elipse de dois focos.

    O que continua mecânico

    Verificar uma derivação pronta continua sendo mecânico: cada linha se confere pela forma. As derivações desta página passaram por um verificador que não sabe o que 0, s ou + significam — ele aceita as sete corretas e rejeita as quatro falaciosas exatamente na linha marcada.

    E há um meio-termo. Se uma sentença é teorema, uma busca exaustiva por derivações acaba por encontrá-la; se não é, a busca pode não terminar nunca. Buscar provas é possível; decidir se existe uma, não.
